# lvgl-CYD-4827
Basic lvgl sketch running on a cheap yellow display JC827W543 resistive
THE CYD has a ESP32S3 and 8MB PSRAM. A typical Guifion from Aliexpress
The sketch shows a very simple touch UI written with lvgl
